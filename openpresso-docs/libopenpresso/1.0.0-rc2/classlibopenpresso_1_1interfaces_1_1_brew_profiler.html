Detailed Description

Interface for automated brew profile execution with step-based control flow.

Performs execution of user-defined brewing profiles with multiple steps, each with a specific control target (constant pressure or constant flow) and advancement condition (weight reached, time elapsed, etc.).

Inherits activation control from ControllerBase. While active, notifies clients of step changes via callbacks.

Note
Supported implementation configs: BrewProfilerConfig
When activated, BrewProfiler tares the associated weight sensor

Set the auto-stop condition based on the elapsed brew time.

With this condition set, brewing stops automatically when total elapsed time since brew start reaches the specified duration. Brew process still can be stopped earlier if the last step in the sequence reaches its transition condition or deactivate() was called manually.
