Detailed Description

Interface for digital input with callback support.

Represents binary input devices like buttons, switches, or digital sensors that report their state (high/low) with optional callback notifications.

Note
Supported implementation configs: LogicalInputPinConfig, AcZeroCrossSensorConfig
