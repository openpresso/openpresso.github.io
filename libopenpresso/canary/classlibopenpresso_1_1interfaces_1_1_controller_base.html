Detailed Description

Abstract base interface for all controllable devices.

All controllers (pressure, temperature, flow rate, etc.) inherit from this interface to provide consistent activation/deactivation semantics.

virtual void libopenpresso::interfaces::ControllerBase::activate ( )

Activate the controller to start regulation.

After activation, the controller will assume unique control over underlying device driver class. May spawn internal threads, start periodic control loops or subscribe to sensor updates as needed.

◆ deactivate()

virtual void libopenpresso::interfaces::ControllerBase::deactivate ( )
pure virtual

Deactivate the controller, stopping regulation.

After deactivation, the controller should stop all control actions and will power down associated hardware (heaters, pumps, etc.).
