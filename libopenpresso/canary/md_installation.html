Installation

This page describes supported ways to consume libopenpresso. Given that libopenpresso itself uses conan and cmake in its builds, having one of these tools in your project will simplify things a lot.

Pick an option that best fits your project:

  • Conan package managerConan package manager
  • CMake FetchContentCMake FetchContent
  • Add sources as cmake subdirectoryAdd sources as cmake subdirectory
  • Download binaries from GitHub ReleasesDownload binaries from GitHub Releases
  • Build from sourcesBuild from sources

Conan package (preferred)

Use Conan package manager to install libopenpresso as a dependency to your project. This will make sure that all subdependencies are managed correctly and can be found by their consumers. Conan also provides a convenient way to manage build toolchain via profiles and CMakeToolchain generator, which is especially useful for cross-compiling.

  1. Add openpresso official remote:
    conan remote add openpresso-conan https://conan.cloudsmith.io/openpresso/canary
  2. Add requires statement to your conan recipe:
  • conanfile.py
    from conan import ConanFile
    class ExampleRecipe(ConanFile):
    def requirements(self):
    self.requires("libopenpresso/0.0.0-6-g2f5af31")
  • conanfile.txt
    [requires]
    libopenpresso/0.0.0-6-g2f5af31

Then in your cmake project simply write:

find_package(libopenpresso)
target_link_libraries(myapp PRIVATE libopenpresso::libopenpresso)
Remarks
For more information, including how to consume conan-installed packages in build systems other than cmake, see conan documentation.

CMake FetchContent

For projects using CMake as build system without external package manager:

include(FetchContent)
FetchContent_Declare(libopenpresso
URL https://github.com/openpresso/libopenpresso/archive/refs/heads/master.zip)
FetchContent_MakeAvailable(libopenpresso)
target_link_libraries(myapp PRIVATE libopenpresso::libopenpresso)
Remarks
For more information see cmake documentation.

CMake subdirectory

You can manually fetch sources from git repo or download archive from GitHub and call add_subdirectory in your project CMakeLists.txt:

git clone https://github.com/openpresso/libopenpresso.git
add_subdirectory(libopenpresso)
target_link_libraries(myapp PRIVATE libopenpresso::libopenpresso)
Remarks
It's recommended to checkout on one of the release tags to be sure you are using a stable version.
Warning
Use the following options carefully and only if your project doesn't use cmake as build system and cannot consume dependencies installed with conan. Build system will not be able to guarantee ABI compatibility and you should take care about matching build toolchains used for compiling libopenpresso and your project.

Precompiled binaries

Libopenpresso provides prebuilt binaries for several popular target architectures. You can download and extract binaries archive from GitHub Releases and manually add corresponding include path and link library to your project.

g++ my_awesome_espresso_app.cpp -I ../libopenpresso/include -L ../libopenpresso/lib -lopenpresso
Remarks
To see what environment was used for build, check openpresso toolchains repo. Libopenpresso CI workflow uses containers from this repo to build the binaries.

Build from sources

If you need to build libopenpresso for specific architecture, with additional compiler flags or just want to change something inside the library, you can build it from sources using container with preconfigured build environment or configure environment by yourself.

Remarks
For more information see cross-compiling guide.
git clone https://github.com/openpresso/libopenpresso.git
cd libopenpresso
docker run -it -v .:/workspace ghcr.io/openpresso/openpresso-toolchain-armv8 bash
cd /workspace
conan install . --build=missing
cmake . --preset conan-release
cmake --build . --preset conan-release
cmake --install ./build/Release --prefix ./out
exit

Now out directory should have the same structure as the precompiled binaries from GitHub Releases and you can follow instructions from previous sectionprevious section.
