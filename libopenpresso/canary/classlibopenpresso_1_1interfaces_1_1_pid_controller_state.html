Detailed Description

Read-only interface for PID controller internal state inspection.

Provides visibility into the individual PID terms (P, I, D) and their sum for monitoring, tuning validation, and telemetry logging.

Useful for:

  • Tuning PID controller settings
  • Logging and visualisation with graphing tools
