Detailed Description

Configuration for automated brew profile executor.

Performs step by step brewing process according to predefined profile with the following sequence:

  1. Tare weight sensor
  2. Open group head valve
  3. Execute brew steps from predefined profile
  4. Close group head valve
Note
Call interfaces::OpenpressoCore::getBrewProfiler() with the label of this config to get configured component instance.
